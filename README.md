# DNS Security

This repository's website documents a hands-on study of DNS security, developed as part of a Master's dissertation at Instituto Superior Técnico (IST). It covers both defensive mechanisms that strengthen DNS integrity and privacy, as well as a broad range of attack techniques demonstrated in GNS3, a controlled lab environment.
